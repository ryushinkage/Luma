# Sleep Analytics Mobile

Flutter mobile app for Sleep Analytics.

## Product idea

Sleep Analytics is a mobile and web application for tracking sleep, analyzing long-term sleep patterns, and generating personalized AI recommendations.

## Main features

- Google OAuth login.
- Quick sleep entry creation.
- Sleep history.
- Sleep statistics.
- AI reports.
- AI sleep-coaching recommendations.
- Push reminders.
- Premium subscription support.

## Tech stack

- Flutter
- Dart
- REST API
- ASP.NET Core backend
- PostgreSQL database
- Google OAuth
- PayPal subscription integration
