# Visual Direction

## General style

The Sleep Analytics mobile app should look like a premium dark-themed AI wellness platform.

It should feel like a combination of:

- Linear;
- Stripe;
- Oura;
- WHOOP;
- Notion;
- modern AI startup dashboards;
- health-tech analytics tools.

The result should be modern, calm, premium and highly polished.

## Mood

The mood should be:

- calm;
- intelligent;
- futuristic;
- trustworthy;
- soft;
- night-inspired;
- wellness-focused;
- analytical.

## Keywords

Use these visual keywords:

- dark theme;
- night atmosphere;
- premium SaaS;
- AI analytics;
- soft glow;
- glassmorphism;
- smooth gradients;
- rounded cards;
- spacious layout;
- clean typography;
- minimalistic dashboard;
- subtle neon accents.

## What to avoid

Avoid:

- old fitness app style;
- bright colorful dashboard;
- crypto-style neon overload;
- corporate hospital website look;
- too many charts on one mobile screen;
- aggressive red warnings;
- scary medical language;
- childish illustrations;
- cluttered layouts.

## UI feeling

The user should feel:

- “This app understands my sleep.”
- “This looks premium and intelligent.”
- “The analytics are easy to understand.”
- “The AI assistant gives useful sleep coaching.”
- “The app is calm and not stressful.”

## Dark theme

The app must use dark theme only.

Light theme should not be implemented unless explicitly requested later.

## Premium feeling

To create a premium feeling:

- use generous spacing;
- use large clean headings;
- use rounded cards;
- use subtle shadows;
- use gradients for primary actions;
- use calm accent colors;
- avoid dense information blocks;
- use elegant chart previews;
- keep UI hierarchy clear.

## AI-related visual style

AI-related blocks should feel like a smart analyst, not a chat bot.

AI cards should look slightly more premium than regular metric cards.

Use:

- gradient borders;
- soft purple/blue glow;
- compact summaries;
- clear recommendations;
- confidence/status indicators where useful.

Avoid:

- chat bubbles as the main AI interface;
- cartoon robot icons;
- excessive “magic” effects.
