# 02. Mobile app requirements

## Технологии

- Flutter
- REST API для backend
- Google OAuth
- Push notifications

## Главная роль mobile app

Мобильное приложение должно быть быстрым ежедневным интерфейсом пользователя. Оно нужно не столько для сложной админки, сколько для регулярного использования:
- быстро добавить сон;
- быстро добавить факторы дня;
- быстро посмотреть статистику;
- получить рекомендации;
- получить push-напоминания.

## Основные экраны

### Onboarding
Цель:
- объяснить ценность продукта;
- показать, что Sleep Analytics анализирует сон и помогает улучшать режим;
- подвести пользователя к Google OAuth.

### Auth
Функции:
- авторизация через Google;
- регистрация через Google;
- сохранение состояния пользователя.

### Home / Today
Функции:
- краткая сводка за последнюю ночь;
- длительность сна;
- оценка качества сна;
- эффективность сна;
- регулярность;
- главный AI-инсайт дня;
- быстрые действия.

### Add sleep record
Функции:
- быстрое добавление записи сна;
- время отхода ко сну;
- время пробуждения;
- длительность;
- субъективная оценка;
- optional: фазы сна, если есть источник данных;
- optional: пульс, SpO₂, давление, если есть источник данных.

### Daily factors / habits
Функции:
- кофеин;
- физическая активность;
- стресс/самочувствие;
- экранное время вечером;
- другие привычки, влияющие на сон.

### Statistics
Функции:
- графики длительности сна;
- графики регулярности;
- тренды качества;
- сравнение периодов в упрощённом виде.

### AI recommendations
Функции:
- персональные рекомендации;
- план улучшения сна;
- список конкретных действий;
- прогресс по целям.

### Reports
Функции:
- weekly AI report;
- monthly AI report;
- summary изменений;
- причины ухудшения/улучшения.

### Notifications settings
Функции:
- push-напоминания о сне;
- напоминания внести данные;
- smart reminders по целям;
- управление частотой уведомлений.

### Profile
Функции:
- профиль пользователя;
- Premium-статус;
- настройки;
- выход из аккаунта.

## Free/Premium в mobile

### Free
- базовые метрики;
- ограниченная история;
- простые графики.

### Premium
- AI-ассистент;
- глубокие тренды;
- корреляции привычек и сна;
- расширенная история;
- smart reminders;
- отчёты и рекомендации.
