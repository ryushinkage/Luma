# 02. Web frontend requirements

## Технологии

- React
- Vite
- Google OAuth для авторизации
- REST API для связи с backend

## Основные страницы web-приложения

### Landing / Marketing page
Нужна для базовой информации о сервисе:
- что такое Sleep Analytics;
- чем продукт отличается от обычного трекера сна;
- какие метрики анализируются;
- как работает AI-ассистент;
- преимущества Premium;
- CTA для регистрации.

### Auth pages
Функции:
- вход через Google OAuth;
- регистрация через Google OAuth;
- обработка состояния авторизации.

### User dashboard
Функции:
- краткая сводка сна за последний день/неделю;
- основные метрики;
- предупреждения/индикаторы;
- быстрый переход к AI-отчёту;
- быстрый переход к добавлению записи.

### Sleep records
Функции:
- добавление записи о сне;
- редактирование записи;
- просмотр истории записей;
- удаление записи, если бизнес-правила это разрешают.

### Statistics / Analytics
Функции:
- график сна по дням;
- тренды за неделю/месяц;
- регулярность сна;
- sleep debt;
- эффективность сна;
- сравнение периодов;
- smart events на графиках.

### AI reports
Функции:
- просмотр AI-отчётов;
- недельные/месячные summary;
- объяснение изменений качества сна;
- рекомендации и конкретные действия.

### Profile / Account
Функции:
- данные пользователя;
- настройки;
- статус подписки;
- управление Premium;
- экспорт отчётов, если доступен.

### Admin panel
Функции:
- управление пользователями;
- управление подписками;
- просмотр сервисной аналитики;
- управление правилами рекомендаций/инсайтов;
- модерация.

## UI-идея

Стиль: modern premium dark-themed SaaS / health-tech analytics.

Референсы по ощущению:
- Linear;
- Stripe;
- Oura;
- WHOOP;
- Notion;
- современные AI SaaS dashboard.

В интерфейсе важно показать, что это не просто дневник сна, а аналитическая система: графики, тренды, AI-инсайты, риск-индикаторы, персональный план.
