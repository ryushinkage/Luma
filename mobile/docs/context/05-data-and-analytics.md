# 05. Data and analytics

## Метрики сна

Система должна анализировать:

1. Duration — длительность сна.
2. Sleep quality — качество сна.
3. Sleep phases, если доступны:
   - light sleep;
   - deep sleep;
   - REM;
   - awake time.
4. Sleep efficiency — эффективность сна.
5. Regularity — стабильность времени засыпания и пробуждения.
6. Schedule variability — вариативность графика.
7. Physiological metrics, если есть источник:
   - средний/ночной пульс;
   - SpO₂;
   - давление.
8. Behavior factors:
   - кофеин;
   - физическая активность;
   - стресс/самочувствие;
   - экранное время вечером;
   - другие привычки.

## Дашборды и графики

Основной фокус — анализ графиков сна.

Нужны:
- график сна по дням;
- тренды за неделю;
- тренды за месяц;
- регулярность;
- sleep debt;
- эффективность;
- сравнение периодов;
- smart events на графике;
- инсайты “что повлияло”.

## Sleep debt

Sleep debt — накопленный дефицит сна относительно целевого значения.

Пример логики:
- targetSleep = пользовательская цель или системное значение;
- dailyDebt = targetSleep - actualSleep;
- если actualSleep меньше targetSleep, debt растёт;
- если actualSleep больше targetSleep, долг может частично компенсироваться.

Формулу можно уточнять, но смысл должен сохраняться.

## Regularity

Regularity показывает стабильность режима.

Учитываются:
- разброс времени отхода ко сну;
- разброс времени пробуждения;
- резкие сдвиги графика;
- стабильность по неделе/месяцу.

## Sleep efficiency

Sleep efficiency — отношение времени сна ко времени в постели.

Если нет данных awake/time in bed, показатель может быть приблизительным или отсутствовать.

## Risk indicators

Система может показывать предупреждения/индикаторы:
- хронический недосып;
- сильная нерегулярность;
- низкая эффективность сна;
- возможное переутомление;
- возможное влияние стресса;
- ухудшение восстановления.

Важно: это не медицинский диагноз.

## Correlations

Premium-функция: корреляции между привычками и качеством сна.

Примеры:
- кофеин вечером связан с ухудшением качества сна;
- высокий стресс связан с меньшей эффективностью;
- физическая активность может улучшать сон;
- экранное время вечером может ухудшать засыпание.

Корреляции нужно формулировать осторожно: “возможно связано”, “наблюдается паттерн”, а не “точно является причиной”.
