# 01. Product overview — Sleep Analytics

## Что это за продукт

Sleep Analytics — сервис анализа качества сна с использованием AI.

Это мобильное и веб-приложение для:
- отслеживания показателей сна;
- анализа привычек пользователя;
- построения долгосрочной динамики сна;
- формирования персонализированных рекомендаций с помощью AI;
- sleep-coaching сопровождения;
- выявления риск-индикаторов на уровне предупреждений.

Важно: продукт не является простым sleep tracker. Это AI-driven health-tech / wellness analytics платформа.

## Основные цели продукта

1. Вести долгосрочную динамику сна: неделя, месяц, квартал.
2. Выполнять динамический мониторинг состояния пользователя на основе метрик сна и поведения.
3. Формировать персональные рекомендации: режим сна, гигиена сна, привычки, восстановление.
4. Адаптировать рекомендации к прогрессу пользователя.
5. Показывать риск-индикаторы:
   - хронический недосып;
   - нерегулярный режим;
   - низкая эффективность сна;
   - признаки усталости;
   - признаки стресса;
   - ухудшение восстановления.

## Что нельзя делать

- Нельзя позиционировать приложение как медицинскую диагностику.
- Нельзя обещать лечение заболеваний.
- Нельзя добавлять роль врача или внешнего специалиста: в рамках проекта их нет.
- Нельзя заменять медицинскую консультацию AI-ассистентом.

Правильная формулировка: система даёт wellness-рекомендации, sleep-coaching, аналитику и предупреждения об индикаторах риска.

## Роли пользователей

### User
Пользователь:
- ведёт записи сна;
- добавляет поведенческие факторы;
- смотрит графики и аналитику;
- получает AI-инсайты;
- выполняет план улучшения сна;
- общается с AI-ассистентом.

### Admin
Администратор:
- управляет пользователями;
- управляет подписками;
- управляет контентом рекомендаций и правилами инсайтов;
- следит за аналитикой сервиса;
- модерирует контент/данные, если это предусмотрено;
- управляет интеграциями.

## Монетизация

Есть две основные версии:

### Free
- базовые метрики за день;
- простые графики;
- ограниченный период истории.

### Premium
- расширенная аналитика;
- долгосрочные тренды;
- AI-ассистент;
- корреляции “привычки → качество сна”;
- смарт-напоминания и цели;
- расширенная история;
- экспорт отчётов.
