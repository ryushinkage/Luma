# 08. Diagrams

В проект добавлены draw.io диаграммы. Их нужно использовать как архитектурный контекст.

## Файлы

### `docs/context/diagrams/sleep_analytics_diagrams-final.drawio`
Содержит страницы:
1. Smart Use Case Diagram
2. Class Diagram
3. Object Diagram

Использовать при задачах про:
- use cases;
- классы/сущности;
- объектные примеры;
- связи доменной модели.

### `docs/context/diagrams/sleep_analytics_uml-final.drawio`
Содержит страницы:
1. Statechart Diagram
2. Component Diagram
3. Deployment Diagram

Использовать при задачах про:
- состояния объектов/пользователя/подписки;
- компоненты системы;
- deployment/развёртывание;
- взаимодействие web/mobile/backend/database/AI API/PayPal/Google OAuth.

## Важное правило

Если код или архитектурное решение конфликтует с диаграммами, сначала проверить, не устарели ли диаграммы. Если нет явного указания, считать диаграммы частью текущего ТЗ.
