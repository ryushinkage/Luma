# 03. Backend requirements

## Технологии

- ASP.NET Core
- PostgreSQL
- REST API
- Google OAuth integration
- PayPal integration
- AI API integration

## Основные обязанности backend

Backend отвечает за:
- авторизацию и пользователей;
- хранение записей сна;
- хранение факторов/привычек;
- генерацию аналитики;
- работу с подписками;
- интеграцию с AI API;
- административную панель/админские endpoints;
- безопасность данных.

## Основные модули backend

### Auth module
Функции:
- Google OAuth;
- создание пользователя при первом входе;
- выдача токенов/сессий;
- проверка роли пользователя;
- logout / revoke, если предусмотрено.

### User module
Функции:
- профиль пользователя;
- настройки;
- роль пользователя;
- статус подписки;
- ограничения Free/Premium.

### Sleep records module
Функции:
- создать запись сна;
- получить записи пользователя;
- получить запись по id;
- обновить запись;
- удалить запись, если разрешено;
- валидация дат и метрик.

### Habit / behavior factors module
Функции:
- хранить поведенческие факторы;
- связывать факторы с конкретной датой или записью сна;
- использовать факторы в аналитике и AI-инсайтах.

### Analytics module
Функции:
- базовые метрики за день;
- недельные/месячные тренды;
- sleep debt;
- regularity score;
- sleep efficiency;
- сравнение периодов;
- risk indicators;
- подготовка данных для AI API.

### AI module
Функции:
- подготовить безопасный контекст для AI API;
- получить AI-рекомендации;
- сохранить AI-отчёт;
- создать weekly/monthly summary;
- объяснить пользователю изменения сна простым языком.

### Subscription / payments module
Функции:
- PayPal payments;
- Premium subscription;
- проверка активной подписки;
- ограничение Premium-функций;
- админское управление подписками.

### Admin module
Функции:
- управление пользователями;
- управление подписками;
- аналитика сервиса;
- управление правилами рекомендаций/инсайтов;
- модерация.

## REST API — базовые группы endpoints

Примерная группировка:

- `/api/auth/*`
- `/api/users/*`
- `/api/sleep-records/*`
- `/api/habits/*`
- `/api/analytics/*`
- `/api/ai-reports/*`
- `/api/subscriptions/*`
- `/api/admin/*`

Не изобретать GraphQL, если отдельно не попросили. По проекту утверждён REST API.
